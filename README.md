# Kikiscurls and Co – AI Customer Service & Order Bot 💇🏾‍♀️

A Telegram bot that answers customer questions and takes orders for
Kikiscurls and Co, an online braiding hair extension business in Lagos, Nigeria.

## Features
- Answers questions about products, prices, hours and delivery using AI
- Only answers from real business info (no made-up prices)
- Takes orders: collects name, phone, product, bundles and address
- Confirms the order with the customer before saving
- Saves orders to Google Sheets automatically, with totals calculated
- Sends customers to WhatsApp for payment

## Built with
- Python
- python-telegram-bot
- Groq API (AI model)
- Google Sheets API (gspread)
